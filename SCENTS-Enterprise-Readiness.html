Next Steps

Phased enterprise readiness plan.

Phase 1
Foundation

Weeks 1–4: Cloud foundation and container registry

  • Provision AWS account and enable EKS in af-south-1
  • Run Terraform to create VPC, subnets, NAT, EKS cluster, node group
  • Create ECR repositories for scents-api, wismo-gateway, wismo-* services, dashboard
  • Push Docker images to ECR and verify deployments in staging namespace
  • Set up external DNS and TLS via cert-manager + Route53
  • Enable CloudWatch logging for cluster and node groups
Phase 2
Data Stack

Weeks 5–8: Production data services

  • Deploy RDS Postgres with Multi-AZ and automated backups
  • Deploy ElastiCache Redis cluster with replication
  • Deploy JanusGraph on EC2/EKS with persistent EBS volumes
  • Deploy MSK (managed Kafka) with topic configs and retention policies
  • Deploy Druid or ClickHouse for real-time OLAP
  • Implement S3-based Data Lake with lifecycle policies
  • Build GraphQL mutation API for Delphi and knowledge graph writes
Phase 3
Security

Weeks 9–12: Security and compliance baseline

  • Implement Vault or AWS Secrets Manager for all credentials
  • Enable network policies, WAF, and security groups
  • Run initial pen-test and remediate critical findings
  • Draft Data Protection Act 2019 compliance documentation
  • Implement audit logging and tamper-evident storage
  • Prepare client data processing agreements and DPAs
  • Enable MFA for all production access
Phase 4
Observability

Weeks 13–16: Monitoring, alerting, and SLOs

  • Deploy Prometheus + Grafana or AWS Managed Prometheus
  • Define SLOs: availability, latency, throughput, error rate
  • Set up PagerDuty or Opsgenie for on-call rotation
  • Implement distributed tracing (OpenTelemetry)
  • Build runbooks for common failure modes
  • Conduct first incident response drill
Phase 5
Team & Commercial

Weeks 17–24: Hiring and client onboarding

  • Hire CTO/VP Engineering and first 2 backend engineers
  • Hire DevOps/Platform Engineer and Cybersecurity Engineer
  • Hire Head of Commercial and 2 Client Intelligence Managers
  • Onboard first 3 enterprise clients under NDA
  • Conduct ISO 27001 gap assessment with auditor
  • Launch Insights API and Intelligence Suite in staging
