# SCENTS × WISMO — Investor & Operations Dashboards

Static, client-side dashboards for EKN Consulting International Ltd.
Published to GitHub Pages (free). No backend — the "live demo" figures are
simulated locally (labelled SIM) and run entirely in the browser.

## Pages
- `index.html` — Investor showcase (Africa Startup Festival, Nairobi, Oct 29–30 2026)
- `scents-background.html` — SCENTS background systems + interactive architecture map
- `scents-usecases.html` — SCENTS use-case explorer
- `wismo-background.html` — WISMO background systems + interactive architecture map
- `wismo-customer.html` — WISMO customer portal (merchant / rider / client)

## Notes
- Brand marks live in `brand/`.
- All metrics are illustrative / SIM unless a live backend is wired in.
